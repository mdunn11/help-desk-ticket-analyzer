# Help Desk Ticket Analyzer

An in-progress Python project that applies foundational programming concepts to a practical IT help desk scenario.

## Overview

The Help Desk Ticket Analyzer is a learning project designed to analyze and manage basic IT support ticket data. I am developing the project as part of my continued technical training in Python, IT support, and systems administration.

The project emphasizes not only writing working code, but also understanding program logic, debugging problems, organizing code into functions, and working with external data.

## Current Features

- Display help desk ticket information
- Search for individual tickets by ticket ID
- Count tickets by status
- Identify high-priority tickets
- Handle invalid user input
- Load structured ticket data from a CSV file
- Organize program behavior into reusable functions

## Python Concepts Demonstrated

This project currently applies:

- Variables and data types
- Lists and dictionaries
- Conditional statements
- `for` loops
- Functions and parameters
- Return values
- User input
- Exception handling
- File handling
- CSV data processing
- Type conversion
- Basic data analysis
